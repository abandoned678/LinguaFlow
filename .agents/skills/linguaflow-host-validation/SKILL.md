# LinguaFlow 宿主验收

## 范围与依据

从本技能目录向上三级是仓库根目录；下列命令均从仓库根目录运行，不依赖固定的本机路径。

先读 [项目规则](../../../AGENTS.md) 和 [首版需求及验收清单](../../../docs/需求与待办.md)。需求中的中文单输入源、分句、超长句降级和 `Control + Return` 原位替换是目标行为，不能从上游 README 推断它们已实现。

按任务选择“需求测试草案”“改动影响分析”或“实际宿主验收”。只整理清单时不安装输入法、不操作真实输入框。

## 建立验收范围

- 分支／提交审查时记录用户指定的 base、merge-base、HEAD，分别列出已提交与工作区改动。范围不明时先用当前工作区，不随意选一个远程基线。
- 读实际 diff 和受影响调用链，把行为变化对应到输入入口、句子缓冲、翻译协调器、浮层或安装注册流程。每条间接回归项注明关联依据。
- 实测前记录 macOS、宿主版本、当前构建提交及未提交改动、输入法 Bundle ID、实际加载路径和模型状态。源码身份不等于运行中的输入法身份。
- 文本编辑与 Codex 分别验收和报告；一个宿主通过不能证明另一个通过。使用空白文档或专门的未发送草稿与合成句子，不能借用已有私人文档作为测试数据，也不能为了验收发送消息。

## 根据变化选择场景

以需求文档的验收表为完整依据，选择本次相关项：

| 变化 | 必须能观察的结果 |
| --- | --- |
| 拼音／候选／按键 | 正常组词、切换候选、确认上屏及退格，不丢字、不重复，不吞宿主 Command 快捷键 |
| 分句／预览 | 逗号不切句，句末后下一句独立累计；400ms 是停顿触发，尚未完成的句子也能预览；超长句不把截断内容伪称整句 |
| 异步翻译 | 继续输入、失焦或清空上下文后，旧结果不再显示或参与替换；模型不可用时仍能正常输入 |
| 主动替换 | 只替换当前追踪句，前文不变，无额外换行或消息发送；组词中、旧译文、范围失效和重复触发不误改 |
| 浮层 | 多行、屏幕底部、窗口移动和滚动时定位可靠；无法定位时隐藏；普通滚动和移动光标区别处理 |
| 生命周期 | 切换输入框、应用、输入源或进入安全输入后，清理上下文，无 marked text 或浮层残留 |

为每个测试点写前置条件、明确操作、可观察预期、影响依据和建议验证方式。数据完整性、重复上屏、误替换和误发送优先于外观检查。核心检查及 Rime 检查不能替代宿主实测；过期请求的确定性验证应在测试替身中控制完成顺序，不能靠快速打字猜测覆盖。

## 执行边界

- 安装、注册、启用输入源和下载模型只在当前任务授权范围内进行；已有授权直接沿用。未授权这些操作时，仍完成清单和可执行的非安装检查，说明缺失的实测条件。
- 当前安装脚本仍涉及上游两套输入源；执行前核对独立开发身份和精确路径。需要构建或诊断时按需读取 [构建技能](../linguaflow-build-debug/SKILL.md)。
- 允许的 UI 自动化不可用或拿不到可靠宿主状态时，将对应项标为未执行／受阻，不以代码阅读冒充实测。真实安全输入场景不可验证时如实报告，不操作用户密码来强行覆盖。

## 交付证据

默认在回复中交付表格：测试 ID、宿主、步骤、预期、实际结果、通过／失败／未执行／受阻及依据。需求和代码不一致时分别陈述，未实现标为需求缺口，不以现状重定义预期。

明确区分静态分析、核心检查、构建、安装注册和真实宿主验收。保留可复现失败步骤，附相关文件位置；只有实际执行的用例才能写通过。不自动持久化原句、译文或完整输入日志；截图仅在必要且授权的合成测试场景使用。
