# 随键译使用建议

## 1. 用快捷键翻译输入框里已有的一句话

记录日期：2026-11-24　状态：待评审

在 Codex 输入框里写好一句中文后，我希望按一次快捷键就能查看这句话的英文译文，省去重新输入的步骤。

**预期效果**　按下快捷键后立即发起翻译，结果就绪时在输入框旁显示英文预览。输入框保留中文原文和光标位置；需要替换原文时，再使用现有的替换快捷键。

**待确认**　新快捷键的组合尚未指定。现有输入法只跟踪本次输入会话中由它上屏的文字。对于粘贴或由其他输入法写入的句子，是否支持用户先选中原文再按快捷键，留待评审。

## 2. 从菜单栏图标看出当前输入语言

记录日期：2026-11-24　状态：待评审

希望随键译支持在中文和英文输入之间切换。切换后，macOS 菜单栏里的随键译图标应立即显示当前输入语言，让我在打下第一个字之前就知道会输入中文还是英文。

建议采用轻量、单色的图标，例如在同一轮廓内用「中」和「A」区分两种状态，在菜单栏的小尺寸下也能辨认。具体图样和切换操作留待执行时确定。

## 3. 在设置中选择单向或双向翻译预览

记录日期：2026-11-24　状态：待评审

希望保留现有的「翻译预览」开关。开启后，可以在设置里选择预览模式：

| 预览模式 | 输入中文时 | 输入英文时 |
| --- | --- | --- |
| 单向（中译英） | 预览英文译文 | 不触发英译中预览 |
| 双向（中英互译） | 预览英文译文 | 预览中文译文 |

选择双向后，连续输入一句中文和一句英文时，两句应分别显示对应的英文和中文预览，无需手动切换翻译方向。关闭翻译预览后，两种语言都可以照常输入，均不显示译文。
