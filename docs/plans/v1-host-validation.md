# 首版宿主验证 Plan

依据 [Spec](../specs/v1-host-validation.md)、[需求验收表](../需求与待办.md#v1-host-acceptance)和 [宿主验收技能](../../.agents/skills/linguaflow-host-validation/SKILL.md)。

- **E1 早期探测。** A3 完成后，核对开发版身份和安装目标，安装授权范围内的隔离构建。文本编辑先行，Codex 分开验证。记录多行光标、组词、移动窗口、滚动、换行和选区接口返回。可用最小本地临时诊断验证有限范围替换，仅操作合成测试文本并检查前后文完整，避免在 Codex 触发发送。生产代码尚未实现替换时，将探测结果标为能力证据，无法验证就标待确认。把发现回填 B1、C3、D1。
- **E2 文本编辑验收。** 使用包含首版改动的构建，运行需求验收表，记录安全输入或模型失败等无法在当前环境复现的条目。失败按具体行为回到对应代码任务修复，再复测受影响条目。
- **E3 Codex 验收。** 使用同一构建在专门的未发送草稿单独测试。关注选字、换行与发送的区别、多行锚点、指定范围原位替换和快捷键拒绝行为。若范围不可验证，记录保持原文和提示结果，同时标明替换功能未通过该宿主验收。

每项记录构建标识、系统、宿主、输入源身份、复现步骤、预期、实际和结论。宿主验证证据可随任务单独记录。安装、模型下载和系统设置操作沿用实际任务已有授权。归档时使用合成数据与必要的测试证据。
