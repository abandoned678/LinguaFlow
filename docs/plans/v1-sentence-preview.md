# 首版当前句与英文预览 Plan

依据 [Spec](../specs/v1-sentence-preview.md) 和 [项目状态测试技能](../../.agents/skills/linguaflow-state-testing/SKILL.md)。从 A1 的构建基线开始。以下每项是一个提交单元。

| ID | 实现与入口 | focused 检查 |
| --- | --- | --- |
| B1 | 调整 `CommittedSentenceBuffer` 和输入控制器的提交／换行／退格处理。处理一个 commit 包含多个句子。换行集成使用可确认的宿主事件，未知行为交给 E1 确认。 | 句内标点、小数点、连续两句、多句 commit、真实换行和句尾退格。确认组词 Return 与宿主发送不被当作换行。 |
| B2 | 核对 `LiveTranslationDraft`、候选变更和 `updateTranslationDraftAndPanel`。候选只进入临时源文，实际 commit 才进入追踪缓冲。 | 上一句句末后开始组词、快速换候选、候选与上屏文本不同、旧请求晚到。若现有行为已满足契约，只补缺失的证据。 |
| B3 | 在缓冲及预览状态表示超长，接入面板提示、取消旧请求和替换禁用条件。保留识别新句的能力，不把尾部重新作为完整句。 | 恰好 280 字、超过一字、临时候选导致超限、旧译文晚到、超长句结束后新句恢复。 |

每项先定位可复现的失败检查，再修改行为。输入变化运行核心和 Rime 自检，UI 或翻译变化构建两项产品。实际宿主差异记入 E1 或最终验收，不从核心自检推断宿主兼容。
