# 首版宿主验证 Spec

对应 [E1–E3](../MASTER_CHECKLIST.md) 和 [执行计划](../plans/v1-host-validation.md)。

实际宿主为文本编辑和 Codex。用空白文档或未发送的测试草稿、合成句子和隔离开发版验证。记录宿主及 macOS 版本、构建提交、加载路径、输入源身份、模型状态、操作步骤、预期与实际结果。

- 早期探测分开确认锚点、选区／组词范围、换行和指定范围写入能力。宿主返回一个范围或替换 API 可以调用，仍须观察实际文本变化才能确认支持。
- 最终在两个宿主运行[首版验收表](../需求与待办.md#v1-host-acceptance)。模型异常、晚到结果、组词及误发送均需有可复核的对应结果。
- 结果按宿主标记通过、失败、未执行或受阻。无法确认替换范围时验证保留原文。将产品功能通过与降级路径通过分别记载。
