# 首版主动整句替换 Spec

对应 [D1](../MASTER_CHECKLIST.md) 和 [执行计划](../plans/v1-sentence-replacement.md)。

`Control + Shift + T` 在已提交中文、无组词、无选区且光标仍在已追踪句尾时，用对应最新原句的译文原位替换。只覆盖当前句及其句末标点，保留前文、换行和其他内容。替换后清理追踪和预览，重复触发保持文本不变。

仍在组词、译文未就绪或已过期、超长、光标或选区失效、宿主范围无法验证时，保留原文并提示暂不可用。已识别的替换快捷键不能透传为宿主发送。停用旧的追加与换行插译分支。

使用宿主支持的指定范围替换。只能核对当前已追踪范围，禁止扫描历史文本或模拟多次退格。范围计算采用 UTF-16。文本编辑与 Codex 的可用性分别以实际验证为准。
