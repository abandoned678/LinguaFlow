# 首版当前句与英文预览 Spec

对应 [B1–B3](../MASTER_CHECKLIST.md) 和 [执行计划](../plans/v1-sentence-preview.md)。

- 已提交缓冲只跟踪当前输入会话中由本输入法上屏的当前句。以 `。！？!?` 或已确认的宿主换行结束当前句。句内标点与英文句点留在原句。句尾退格更新被追踪的文本，开始下一句时旧译文失效。
- 停顿约 400ms 后预览。高亮候选可以参与当前预览，已结束的上一句不与下一句候选拼接。候选上屏后按实际 commit 记入缓冲。
- 当前句超过 280 字时暂停预览和替换并提示，下一句可恢复。候选参与预览时同样检查源文长度。纯预览不得修改宿主内容。
- 使用 Apple 设备端翻译。翻译失败或模型未安装时，中文输入与选字仍可完成。过期结果和错误不能覆盖当前状态。

宿主换行以 E1 观察结果为依据。普通 Return 可能用于发送或确认组词，不能仅凭键码确认宿主插入了换行。
