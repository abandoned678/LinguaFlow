# 首版开发基线与中文分发 Spec

对应 [A1–A3](../MASTER_CHECKLIST.md) 和 [执行计划](../plans/v1-development-build.md)。

开发者可以在 Apple 芯片 Mac 上复现当前构建，在同一台机器测试独立的 LinguaFlow 开发版。首版的构建、安装与注册入口只提供中文输入源，保留用于准备本地模型的设置助手。

## 验收

- 记录未修改产品行为时的源码提交、子模块版本、macOS、Swift、librime 和 OpenCC，以及两项构建和自检结果。模型未安装按实际状态记录。
- 开发版的显示名称、Bundle ID、输入源 ID、IMK 连接名和 Rime 用户数据目录与上游版隔离。设置助手、构建产物、安装目标和注册验证使用相匹配的身份。
- 首版安装产物只含中文输入源及其助手和运行资源。即使构建目录残留上游 English 产物，安装包仍只收录当前目标。
- 开发安装与迁移只操作已核对的精确路径和身份。保留上游安装、Rime 用户数据和许可文件。

开发身份只服务本地测试。正式品牌、发行身份和公开签名留在原需求的 P2。
