# 首版光标浮层与会话清理 Spec

对应 [C1–C3](../MASTER_CHECKLIST.md) 和 [执行计划](../plans/v1-caret-lifecycle.md)。

- 当前选区光标或组词位置提供首选锚点。字符索引 0 的行矩形只有在能可靠反映当前输入位置时才作兜底。浮层优先在下方，空间不足时在上方。无法定位时隐藏。
- 移动窗口和滚动时重新验证位置。若位置无效，清除旧锚点。若同时检测到选区或光标变化，按当前句上下文失效处理。
- 失焦、停用、切换输入源、导航和安全输入清理句子及翻译状态。停用后宿主无 marked text，浮层隐藏。取消前开始的翻译即使晚返回也不会恢复面板。
- 宿主 Command 快捷键保留原行为。组词内候选移动和退格继续由 Rime 管理。共享浮层的更新和隐藏受当前会话约束。

首版覆盖文本编辑和 Codex 的常用多行、屏幕底部、窗口移动和滚动。扩展多屏及复杂编辑场景见 P1。
