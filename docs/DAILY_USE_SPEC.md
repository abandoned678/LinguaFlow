# 随键译 · 日常可用性规格

状态：待实施。范围覆盖六个批次，首阶段交付批次 1–3。实施步骤见 [任务计划](DAILY_USE_PLAN.md)，首版行为与历史实测见 [首版需求与验收](V1_REQUIREMENTS.md)。

## S1 · 统一设置与全局开关

沿用随应用打包的 `SentenceAlongSetup.app`。输入法菜单依次提供「启用翻译预览」（勾选项）、「输入法设置…」和「准备本地翻译模型…」。设置项打开同一窗口，准备入口定位至「翻译」页，即使助手已在运行也能正确定位。打开该页只显示状态，下载由页内显式操作触发。

| 页面 | 设置或操作 | 默认值 | 可用批次 |
| --- | --- | --- | --- |
| 翻译 | 启用翻译预览 | 开启 | 1 |
| 翻译 | 响应速度（快速／均衡／节能） | 均衡 | 3 |
| 翻译 | 模型状态、检查、准备及重试 | 尚未检查，检查后据实显示 | 1 接入现有准备入口，2 完成状态与验证 |
| 外观与操作 | 预览布局（精简／完整） | 完整 | 4 |
| 外观与操作 | 浮层字号（小／标准／大） | 标准 | 4 |
| 外观与操作 | 替换快捷键 | Control + Shift + T | 4 |
| 关于与诊断 | 版本、构建号、诊断、自检、开源许可 | 显示当前环境及可用操作 | 1 接入基础信息，后续随诊断能力补齐 |

设置字段通过一份共享模型定义。IME 与助手使用同一个明确的持久化域，通过跨进程通知双向同步。通知仅表示配置已变更，接收者从共享域重读，IME 激活和助手打开或重新激活时也补读。写入在通知前完成，编辑单个字段保留另一进程的其他字段。缺失、非法或无对应迁移的数据按字段使用默认值，已支持的旧版本迁移可重复执行。本地安装、升级与两个进程重启后保留偏好。偏好域只保存设置和版本，无原句、译文或翻译历史。

关闭时，同步撤销当前译文的显示与替换资格，隐藏翻译区，取消等待、超时计时和进行中工作，清空翻译缓存，停止后续输入触发的模型调用。已在途的结果和错误均失效。Rime 组词、候选、上屏和学习照常运行。替换快捷键保留正文，可提示「翻译预览已关闭」。设置窗口的用户主动模型准备仍可使用。全局开关也约束保留英文路径的候选释义模型调用，拼写与候选选择继续可用。

重新开启时，仅在当前 controller、宿主焦点、光标与追踪上下文均有效且处于普通输入时，使用当前已追踪的可翻译内容继续预览。关闭期间按现有规则追踪本输入法的当前句。若切焦点、光标失效或进入安全输入，历史内容不会恢复。开关全局生效，切换应用时沿用同一设置。

## S2 · 调度、取消与恢复

调度状态覆盖隐藏、等待防抖、正在请求、可用、失败和超时。状态包含当前请求需要的身份信息，渲染和替换从同一状态读取。输入事件正常返回，翻译异步执行。

- 每次实际请求具有独立身份，清理上下文或关闭开关推进生命周期。结果、错误、超时和缓存命中在发布前校验当前请求身份、生命周期、原文、开关及输入上下文。原文一变即撤销旧译文的替换资格。
- 进行中收到新内容时只保留一个最新待执行内容，淘汰较旧的等待项。旧会话的取消只影响它所拥有的底层会话。取消后的 Apple 会话应弃用。分别观察底层是否停止和应用是否已停止接受结果，根据实测约束底层并发及资源保留。
- 模型调用发出后初始超时为 3 秒，防抖阶段独立计时。超时立即结束加载并提示「翻译超时，可重试」，后续迟到的结果无效。普通失败与超时提供对当前有效原文的显式重试，重试使用新请求身份，再次校验焦点和上下文。模型缺失提示通过设置准备，并停止同一缺模型条件下的重复自动尝试，验证就绪后恢复。
- 失焦、停用、切输入源、导航、选区、追踪光标失效、安全输入及宿主编辑导致的失效沿用现有清理契约。停用后无 marked text 或浮层残留。保留 280 字上限与宿主换行对账。

## S3 · 触发规则与会话缓存

以下数值用于首轮测量。

| 触发 | 快速 | 均衡 | 节能 |
| --- | ---: | ---: | ---: |
| 普通输入停顿 | 120 ms | 200 ms | 400 ms |
| 高亮候选变化 | 80 ms | 120 ms | 250 ms |
| 已提交句末标点 | 立即 | 立即 | 立即 |
| 当前会话缓存命中 | 立即 | 立即 | 立即 |

controller 传递明确的触发原因和句末状态。仅确认组词、原文相同且请求已排队、执行或完成时，复用现有工作。同文从临时稿变为已确认句末时，提前执行等待任务，已经开始的同文请求继续。只有真正上屏的句末标点适用立即调度，宿主 Return 是否换行仍以宿主对账为准。候选变化和普通打字各自按其事件语义判断。

当前有效会话使用容量 32 的内存 LRU。键由原文、语言方向和实际翻译策略组成。只保存成功的非空完整结果，命中后绑定最新请求修订号并执行与普通结果相同的校验。失焦、上下文失效、安全输入和关闭时清空。速度档控制调度时间，模型策略由运行环境统一决定。

## S4 · 模型检查、准备与验证

IME、设置助手和 `translation-checks` 共享语言方向、策略、系统版本分支、就绪判定和错误分类。保留当前中译英及现有英译中验证能力，逐方向展示结果。准备流程结束后，对运行时使用的策略与语言方向分别调用设备端翻译，以固定合成句得到非空结果后才标记对应方向就绪。准备、检查与输入预览之间的状态刷新可用无文本的状态通知驱动。早期系统分支与支持低延迟策略的系统分支均纳入验证。

| 状态 | 展示与动作 |
| --- | --- |
| 尚未检查 | 检查模型 |
| 模型未就绪 | 准备模型 |
| 准备中 | 显示进度状态，等待系统确认或准备完成 |
| 已就绪 | 显示验证通过的语言方向 |
| 准备失败 | 简短原因及重试入口 |

检查和普通输入均使用已安装模型能力，下载确认只由用户点击「准备模型」触发。模型缺失、系统或框架不可用、超时和普通失败具有可辨认的恢复入口。

## S5 · 浮层与主动替换

防抖期间呈现轻量等待状态，模型调用开始才显示「正在翻译」。同一句的连续更新适度固定翻译区域高度。原文变化后清除旧译文。精简模式在组词时显示候选，译文就绪后展示译文及必要状态。完整模式保留原文、译文及必要状态。字号同步用于测量、绘制和换行，控制候选及长文本在多屏缩放与边缘场景的可读性。

只有显式触发替换、中文已经上屏、译文对应最新原文、宿主无选区且光标和 UTF-16 范围核对均通过时，才以一次操作修改当前句。保留前文和宿主撤销。按实际拒绝原因给出简短提示，包括「请先确认当前组词」「正在等待译文」「翻译预览已关闭」「光标已离开当前句」「当前存在选区」「无法确认宿主文本范围」「当前句超过长度限制」。多条件冲突时由同一判定入口给出稳定的提示优先级，优先处理关闭、失效和明确阻止替换的状态。

快捷键从统一设置配置，默认 Control + Shift + T。录制和保存校验主键、修饰键及宿主默认快捷键边界。保留 Command 快捷键透传；无效或取消录制时保留上一次有效设置。自定义键也经过与默认键相同的替换条件。

## S6 · 候选鼠标操作和本地资源

点击有效候选会提交被点中的当前页项目，翻页只改变候选页，点击其他区域不提交。鼠标操作期间宿主保有输入焦点。候选数量和原有键盘操作按首版继续。鼠标能力独立提交并独立在宿主验收，旧页或已失效会话的点击不得写入。

Rime 引擎状态包括准备中、可用、失败。失败保存可诊断的分类，在菜单或设置显示状态与恢复说明。单次引擎失败不会在每次按键重复初始化或反复输出。翻译故障走翻译状态。应用持有全局 librime runtime，controller 持有各自的会话。

每次快照从 C 桥获取一次 Rime context，在 C 内复制预编辑、候选、备注、高亮等当前快照信息并释放 librime 资源。Swift 接收独立数据。优化前后核对提交结果、候选顺序、分页、标记文本和按键结果，再比较耗时及分配。

浮层尺寸按实际内容、字号及相关显示条件失效，在条件相同的刷新中复用。同一输入事件复用光标查询，保留下一事件及定期上下文复查。记录浮层静止时的 CPU、布局次数与宿主调用次数。自适应位置轮询作为后续实验，须证明上下文失效检测同样及时。分别测量 Rime 初始化、词库维护、会话创建，再决定是否将可提前完成的维护移到安装或准备阶段。

## S7 · 模块边界

| 部分 | 职责 |
| --- | --- |
| 共享设置 | 默认值、校验、版本迁移、持久化、变更通知 |
| 输入状态 | 组词、当前已提交句、句末、上下文有效性 |
| 翻译调度 | 防抖、去重、缓存、取消、超时、统一结果状态 |
| 翻译 provider | Apple 会话、语言方向、模型策略、就绪状态、错误分类 |
| 宿主适配 | 光标、选区、范围核对与替换 |
| 浮层展示 | 状态渲染、尺寸计算、定位、鼠标操作 |
| IMK controller | 接收事件并协调各部分 |

沿既有类型渐进迁移。英文拼写与候选释义维持现有能力，若涉及 controller 拆分，在同等行为检查覆盖下迁移。此次范围限 macOS 设备端翻译和当前会话，按应用偏好、云翻译、历史记录、旧句恢复列为后续议题。

## S8 · 验证、诊断与发布

- 先写能失败的状态检查，再改状态机。以可控时钟和可控制完成顺序的 provider 覆盖开关、并发、丢失通知、速度档、缓存和超时。每批按 [任务计划](DAILY_USE_PLAN.md#验证命令和验收记录) 执行适用的自动检查、构建与真实宿主验收。
- 性能使用相同设备与固定合成语料，按冷／热启动、命中／未命中分组。均衡模式普通输入的端到端预览等待较 400 ms 基线降低至少 150 ms，首轮用同条件普通未命中样本的 P50 比较并同时记录 P95。句末无固定防抖，关闭时输入触发翻译调用量为零，按键路径 P95 无明显退化。反复激活、失焦及切开关后，任务存量和内存应趋稳。报告模型调用、应用提交浮层与实测屏幕出现时间。
- 诊断使用结构化元数据，包括触发原因、长度区间、阶段耗时、取消／超时／命中计数、引擎状态、错误类别、版本和系统信息。只允许清单内字段，原文、译文、剪贴板和宿主文档内容均留在实时工作路径。诊断、自检及导出的内容遵守此边界。
- 发布产物的最低系统版本应与实际 Mach-O 和内嵌依赖相符，需在声明的最低系统实测。产物可追溯到版本、构建号、源码提交及依赖版本。本地安装在临时目录验证后整体替换，覆盖注册失败后的回滚。验收安装、升级、卸载和设置保留。对外发行完成 Developer ID 签名、公证、票据和实际安装检查。详细安装入口见 [构建与安装](INSTALL.md)。
