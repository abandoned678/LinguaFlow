# 随键译 · 日常输入体验优化规格

**状态：三批产品功能已实现，D1–D3 已确认。Codex 单按 Shift 直输英文已验收关闭。批量导入、学习管理和分版本卸载已实现，其余验收按下表跟踪（2026-11-23）。** 新增功能的验证范围见下表；日常可用性历史待验项见独立计划。

**目标：** 在同一个 macOS 输入源中完成日常中文输入、中英混输和双向本地翻译。关闭翻译时，中文组词、候选选择和上屏仍应完整可用。

本稿承接[日常可用性规格](DAILY_USE_SPEC.md)。以下为开发目标；既有构建的实测结果见[验收记录](DAILY_USE_PLAN.md)。本轮聚焦开发版自用体验。

## 1. 预览浮层与设置

精简和完整布局均移除常驻的「⌃⇧T 替换当前句」一行。快捷键可在设置中查看、修改和恢复默认。输入法菜单提供「用译文替换当前句」，右侧显示当前绑定；菜单操作和键盘操作使用相同的替换条件。

| 当前状态 | 浮层行为 |
| --- | --- |
| 拼音组词中 | 展示编号、高亮候选和翻页控件。开启翻译且译文就绪时，在下方显示目标语言和译文；高亮变化后更新预览 |
| 原文已上屏 | 收起候选行；译文就绪后只显示当前句译文及目标语言 |
| 翻译关闭 | 隐藏翻译区，停止模型请求；仍可选词和翻页 |
| 用户主动替换但条件不满足 | 保留正文，短暂显示具体原因，例如「请先确认拼音」或「译文准备中」 |
| 模型缺失、请求超时或失败 | 显示适用的「准备模型」或「重试」入口。用户继续打字时正常上屏 |

| 设置页面 | 项目与默认行为 |
| --- | --- |

| 翻译 | 预览总开关、翻译方向、快速／均衡／节能、按应用偏好、模型检查与准备。默认开启、中译英、均衡；首次下载由用户发起 |
| 外观与快捷键 | 精简／完整布局、字号、替换键、候选翻页键和快捷键恢复默认。沿用已有设置，新用户默认完整布局、标准字号及 ⌃⇧T。冲突或无效的录制保留原值并说明原因 |

菜单保留预览开关、翻译方向及设置入口。菜单与设置共享偏好，重启后保留；升级时保留已有布局、字号、速度和快捷键。各设置项随对应功能交付。

## 2. 候选分页与组词编辑

- **页大小。** 支持 5、6、7、8、9、10 六个值。每页最多显示所选数量，末页按实际数量展示。引擎分页、界面编号、数字选词及鼠标命中使用同一页候选顺序。[Rime 引擎](../Sources/RimeInput/RimeEngine.swift)按本次组词开始时的设置分页，[浮层](../Sources/InputMethod/PreviewPanelController.swift)按同一份候选快照编号、单行排列并计算点击位置。
- **选词。** 空格确认高亮项。数字键选择当前页对应项，第十项标 0，按 0 选择。组词外数字照常输入。点击只提交一次；翻页只改变页面；宿主保留焦点。首末页禁用不可用的翻页方向。
- **布局与生效。** 候选和翻页按钮始终同排。浮层按候选所需宽度横向展开，到达当前屏幕可用宽度时先缩短较长候选的显示文字。大字号、窄窗口或屏幕边缘仍应能看见和点击最后一项。修改页大小后从下一次新组词生效，当前拼音、高亮和页码保留。
- **中途改字。** 左右移动后，宿主标记文本内的可见光标跟随 Rime 的组词光标。即使拼音未改变也要刷新位置。桥接时将引擎位置换算成宿主所需的 UTF-16 范围，覆盖含音节分隔符、ü 的显示文本。候选更新与实际编辑位置一致。

## 3. 混输、翻译方向与触发

| 场景 | 输入及结果 |
| --- | --- |
| 中文 → 英文 | 拼音组词时可预览高亮候选；上屏后预览当前中文句。临时候选尚未上屏时禁止替换 |
| 中文中夹英文 | 保持中译英方向，支持原样提交拉丁字母串后继续中文。组词中按 Return 原样提交当前拉丁输入串。可选的单击 Shift 切中英文默认关闭，只响应单独按下再松开；Shift+A、Shift+数字及系统快捷键保留原行为 |
| 英文 → 简体中文 | 从同一输入源菜单切换后直接键入英文。保留大小写、数字和词间空格，对本次输入的整句预览中文。手动选择的方向跨应用、重启后保留 |

**停顿和标点。** 均衡档下，普通输入停顿约 200 ms、高亮切换约 120 ms 后发起请求；已上屏句末标点可立即发起。上述时间为请求触发延迟。单独键入一个标点（如「。」）也允许出现预览；模型返回与原标点相同的结果可以照常展示。逗号保留上下文。英文直输中的词间空格保留在当前句，句点兼顾小数、网址和缩写。Return 按宿主实际换行或发送语义处理。

**切换与替换。** 切换方向使旧方向的请求、缓存结果和替换资格立即失效。取消当前未确认拼音，保留已上屏正文。两个方向都只允许在原文已上屏、译文最新、无选区、光标在已追踪句尾且宿主范围与原文一致时原位替换一次；宿主撤销可恢复原文。英文直输仅追踪本输入法实际提交的字符。保持 280 字上限，不读取宿主历史，不保存原句或译文。失焦、导航、安全输入及停用时按现有契约清理上下文；输入路径始终不等待翻译。

**按应用偏好。** 每个应用可选「跟随全局／开启预览／关闭预览」，默认跟随全局。有效开关取该应用的显式选择，否则取全局值。切换应用时清理旧句，按新应用的有效开关开始新会话。翻译方向仍沿用用户最后一次手动选择。

## 4. 首选质量、词典与拼音习惯

1. 固定 50～100 条可重复使用的合成语料，覆盖聊天、开发词、长句、简拼和错拼。用相同按键对照随键译、系统拼音及搜狗 Mac，记录词库学习状态、首选命中、前五命中、完成上屏的额外按键数，以及重复选择后首次升到首选的次数。页大小设为 10 时仍按前五口径比较。优先复查「大模型」「接口超时」，用「回退方案」「多模态」检查已有首选是否退化。
2. 个人短语允许输入码映射到指定文本，例如 `sjy → 随键译`。添加或编辑后从下一次组词生效，删除后移除该自定义映射，重启后保留结果。清理学习数据前明确操作范围并确认；保留手动短语和其他偏好。
3. 保留现有简拼与纠错，双拼先接入用户选定的一种方案；模糊音允许分别启用 z/zh、c/ch、s/sh 等组合。记录启用前后目标词排名及新增干扰项，再决定默认值是否需要调整。
