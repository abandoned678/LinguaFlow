## 验证命令和验收记录

在仓库根目录运行适用项。同一工作树中的构建命令顺序执行。状态机测试在实现前保存一次可复现的失败，修复后运行回归；测试替身用可控时钟和信号，真实模型数据用于冒烟及测量。

```sh
swift test
swift run input-core-checks

mkdir -p .build
shared_dir=$(./scripts/prepare-rime-data.sh) || exit
user_data_dir=$(mktemp -d "$PWD/.build/rime-user-check.XXXXXX") || exit
swift run rime-checks "$shared_dir" "$user_data_dir"

swift build --product InputMethod
swift build --product TranslationSetup
swift run translation-checks
swift run -c release translation-checks --benchmark

./scripts/build-app.sh release
./scripts/build-installer.sh release
# 各自安装后核对实际注册和加载路径
./scripts/check-installed-input-sources.swift --local
./scripts/check-installed-input-sources.swift
```

- 输入逻辑变化运行 Core、XCTest 和真实 Rime；UI／翻译变化构建 IME、助手；模型变更执行翻译自检，退出码 2 记录模型缺失。打包时检查应用内助手、动态库、资源与签名。循环性能检查记录任务、会话、观察者和浮层定时器在停止输入后的存量。
- 性能报告在改动前固定硬件、系统、宿主、语料、步骤、正式采样数、统计口径和可分辨的时延差异。起点为最后一个触发输入事件，终点为对应译文首次可见。按键热路径从事件接收到 controller 返回计时，再单列 C 快照和宿主查询。记录测量误差、环境缺项及所用构建。
- 宿主记录宏观环境、载入的构建与 Bundle ID、模型状态、用例、步骤、观察结果和状态（通过／失败／未执行／受阻）。使用合成文本、空白文稿或未发送草稿。宿主验证前确保运行的是待验收构建。

| H02 跨进程开关 | 设置窗口和菜单各切一次，助手打开时双向同步；切应用、重启两进程，再开正在组词的会话 | 勾选即时一致且持久；关闭无模型调用，可继续组词；重新开启只预览有效上下文 |
| H03 替换与撤销 | 在已有前文的文稿中完成中文并替换，再撤销或重复触发；在组词、加载及关闭期间触发 | 只修改当前句，撤销恢复中文，拒绝和重复触发均保留正文，无额外换行或发送 |
| H04 失效与恢复 | 请求中继续输入、移动光标、选区、切换输入框／应用／输入源并返回；在合成安全输入场景复测 | 焦点失效后清理 marked text 和浮层，迟到结果无效，安全输入无预览，返回后可正常输入 |

| H08 候选鼠标 | 点非高亮候选、翻页、点空白区与页边界，随后继续键盘输入 | 选中项只提交一次，翻页只改页面，空白区无提交，宿主焦点和键盘功能均保留 |


## 首阶段验证记录

记录日期 2026-11-16，分支 `codex/daily-use`，本机 Apple Silicon、macOS 27.0.1（26A434）、Swift 6.4.2、已安装双向 Apple 设备端模型。候选构建来自含首阶段工作区修改的 `1fc2b67`。

| 证据 | 结果 |
| --- | --- |
| 设置与进程通信（B1-02–B1-05） | XCTest 覆盖默认值、错误配置、旧版本与独立写入。隔离目录内用真实独立进程并发写入开关和速度，观察进程收到分布式通知并读到新开关，重启后的新进程读到两个值。 |
| 模型策略和取消（B2-01–B2-04、B2-07–B2-08） | 双向同策略探针均通过。在 0、1、15 ms 提交后分别取消合成中译英请求，三次均返回取消，后续请求均成功。取消返回约 4、1、243 ms，Apple 内部工作结束时间未观测。缺模型准备 UI 与 macOS 26.0–26.3 分支仍待实测。 |
| 构建与冒烟 | 22 项 XCTest、`input-core-checks`、真实 `rime-checks` 和双向 `translation-checks` 通过。Release 应用构建及签名校验通过。链接器报告本机 librime 最低 macOS 27；macOS 26 兼容性留待 B6-02。 |
| 调度和缓存（B3-01–B3-06） | XCTest 覆盖三档延迟、标点提前、原文去重、关开及迟到结果、超时重试、缓存即时命中、清理、LRU 淘汰和空结果排除。 |
| 固定防抖对比（B3-07 部分） | `swift run -c release translation-checks --benchmark` 使用同一热模型，400 ms 对照与均衡档各 16 个未命中合成样本。从提交至调度器就绪，P50 为 443.3 → 244.0 ms，P95 为 447.9 → 246.6 ms。宿主按键到屏幕显示、冷模型、按键 P95 与长期内存趋势仍待实测。 |
| 真机宿主（B1-09、B2-10、B3-08） | 已执行核心及真实 Rime 检查。本机系统域安装仍使用原构建，当前执行进程无法注入宿主按键。TextEdit／Codex 的 H01–H05、H07 和首阶段发布验收保持待执行。 |

首阶段的屏幕端到端门槛仍以 S8 为准。调度对照模式固定 400 ms，使用当前 provider 和协调器，不依赖旧提交产物。
